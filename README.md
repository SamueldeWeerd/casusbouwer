# Casusbouwer: veilig én efficiënt werken met coding agents

Een interactieve oefening voor de workshop "Veilig én efficiënt werken met coding agents".
In drie rondes bouw je een opstelling voor een coding agent: waar hij draait, welk model,
welke inlog, welk harnas en welke toestemming. Daarna laat je de opstelling beoordelen
op veiligheid en eenvoud (totaal = 1,5 × veiligheid + eenvoud).

1. **GitLab**: samenwerken met een agent
2. **Je laptop opruimen**
3. **Gevoelige data** (de eindronde)

## Gebruiken

Open de site via GitHub Pages, of lokaal:

```bash
python3 -m http.server 8000
```

en ga naar http://localhost:8000. Er is geen build-stap en er zijn geen afhankelijkheden:
alleen `index.html`, `app.js`, `cases.js` en `style.css`. Je keuzes worden alleen in je
eigen browser bewaard (localStorage).
